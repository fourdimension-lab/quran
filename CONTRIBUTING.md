# Contributing to Al-Quran Platform

We welcome contributions from developers, designers, translators, and Islamic scholars who wish to serve the Ummah by building an open, accessible, and authentic Quranic platform.

---

## Code of Conduct & Sacred Guidelines

1. **Textual Inviolability**: Changes affecting Arabic Quranic text, diacritics, or verse numbering must cite verified canonical Mushaf authorities.
2. **Attribution Requirement**: All translations, Tafsir passages, and Hadith references must state their classical or contemporary authors and dataset versions.
3. **No Speculative Miracles**: Do not introduce unverified numerology, speculative science, or contested historical claims without peer-reviewed citations.

---

## Development Workflow

1. Fork the repository and create your feature branch:
   ```bash
   git checkout -b feature/topic-refinements
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the automated test suite before committing:
   ```bash
   npm test
   ```
4. Build the production bundle to ensure no compile errors:
   ```bash
   npm run build
   ```
5. Submit a pull request detailing your changes and scholarly references.
